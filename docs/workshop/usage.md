# 安装与管理 Mod

在桌面版 Salt Player 中打开「创意工坊 → 模组管理」，可以查看和管理已安装的 Mod

## 本地导入

1. 从 [GitHub 插件列表](https://github.com/topics/salt-player-plugins) 或作者提供的地址下载插件包
2. 打开「模组管理」，点击页面顶部的「导入模组」
3. 选择 `.spmod`、`.jar` 或 `.zip` 插件文件，核对名称并确认导入
4. 打开该 Mod 的操作菜单，选择「启用」，查看权限说明并确认

## Steam 订阅

1. 启动 Steam 并登录拥有 Salt Player 的账号，打开 Steam 渠道的播放器
2. 从「创意工坊」点击「浏览 Steam 创意工坊」，或直接打开 [Salt Player 创意工坊页面](https://steamcommunity.com/app/3009140/workshop/)
3. 在所需 Mod 的 Steam 页面点击订阅
4. 返回「模组管理」查看下载状态，下载完成后手动启用 Mod

新订阅的 Mod 默认禁用。启用后，播放器会保留该条目的启用状态与权限决定

Steam 会管理订阅内容的下载和更新。

成功同步过的订阅可在 Steam 未连接时启用、禁用和配置；获取新订阅、更新和取消订阅需要连接 Steam

## 权限与配置

首次启用时，播放器会显示 Mod 申请的权限及用途。你可以按需勾选；未授予权限时，相应功能可能不可用，部分 Mod 也可能无法启动

常见权限包括注册快捷键、读取曲库等。Mod 在播放器进程中运行，权限控制不等同于系统沙箱，请仅启用信任来源的 Mod

需要调整授权时，先禁用 Mod，再次启用并修改权限勾选。更新新增的权限需要重新确认，不会自动授予

如果 Mod 提供配置界面，可在其操作菜单中选择「配置」；没有声明配置的 Mod 无法使用此入口。配置项的含义请参考作者说明

## 更新与移除

| 操作 | 本地导入的 Mod | Steam 订阅的 Mod |
| --- | --- | --- |
| 更新 | 下载新版插件包，再次导入同一插件 ID 的文件并确认更新 | 由 Steam 下载更新，按播放器提示重启 |
| 临时停用 | 在操作菜单中选择「禁用」 | 在操作菜单中选择「禁用」 |
| 移除 | 在操作菜单中选择「删除」 | 连接 Steam 后选择「取消订阅」 |

删除或取消订阅已加载的 Mod 时，可选择是否同时删除模组用户数据。希望保留配置时，不要勾选同时删除数据

本地文件与 Steam 订阅使用相同插件 ID 时，播放器会提示来源冲突并停用两者。选择要保留的来源，再删除本地副本或取消对应订阅

## 常见问题

### 没有 Steam 创意工坊入口

浏览和发布入口仅在 Steam 渠道提供，其他桌面渠道可以使用本地导入。

### 已订阅但没有生效

在「模组管理」中确认下载已完成、Mod 已启用且所需权限已授予。如果显示更新提示，请重启播放器；如果显示错误，请结合提示检查 Steam 连接和插件兼容性

### 导入失败或启用失败

确认下载的是有效插件包，并检查作者要求的播放器版本、系统和依赖。保留错误信息，向对应 Mod 作者反馈

想制作自己的插件，可继续阅读 [开发入门](getting-started)
