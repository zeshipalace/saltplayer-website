# 音乐库

你可以把歌曲文件或文件夹添加到 Windows 版音乐库。添加文件夹后，刷新音乐库时可以重新扫描其中的音乐。

## 添加音乐

常见方式有两种：

1. 将歌曲文件或音乐文件夹拖到 Salt Player 窗口。
2. 在应用内选择导入文件或导入文件夹。

导入文件夹时，应用会扫描该文件夹及其子文件夹中的可识别音乐。

## 管理曲库

在音乐库中浏览歌曲。若原文件已移动或删除，可以从曲库中移除对应记录；移除曲库记录与删除原始音乐文件是不同操作，请在确认所选操作后再继续。

你也可以在设置中添加常用文件夹。移除自定义文件夹后，后续刷新将不再扫描该位置，但不会自动移除已经加入曲库的歌曲。
