# Salt Player for Windows

Windows 版 Salt Player 面向桌面音乐聆听，提供本地音乐库、播放控制和可配置的音频输出。你可以从 [Microsoft Store](https://apps.microsoft.com/detail/9p42fq0wpqxk) 或 [Steam](https://store.steampowered.com/app/3009140/) 获取。

## 文档

- [下载与安装](./install)：了解两个发行渠道的安装方式。
- [音乐库](./library)：添加歌曲和文件夹，整理曲库。
- [音频播放](./audio)：了解共享和独占音频输出模式。
