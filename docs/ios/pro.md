# Pro

Salt Player 的本地播放、音乐库管理和标准歌词功能免费使用。Pro 提供音频处理、显示设置与跨设备同步方面的可选权益。

## Pro 权益

| 功能 | 说明 |
| --- | --- |
| Morvanium | 使用 Morvanium 的歌曲过渡设置 |
| 均衡器 | 调整本地播放的均衡器 |
| 标签编辑 | 调整 Salt Player 音乐库中的歌曲信息，修改仅在本 App 生效，不写回原音频文件 |
| 频谱动画 | 启用播放器频谱动画 |
| iCloud 同步 | 在使用同一 iCloud 账户的 iPhone 和 iPad 间同步歌单及其封面、收藏、歌曲标签与听歌记录，用于生成听歌统计；不传输音频文件 |
| CarPlay | 在支持 CarPlay 的车辆中浏览和播放音乐 |

Apple Music 会员与 Pro 独立，不包含在 Pro 购买中。

iCloud 同步需在 **设置 > iCloud 同步** 中主动启用，占用您自己的 iCloud 存储空间；不启用同步不影响本地功能。操作与同步范围见 [iCloud 同步入门](/ios/getting-started#icloud-sync)。

## 购买方式

打开 **我的**，点按左上角的星芒按钮进入 Pro 页面。

| 方案 | 类型 |
| --- | --- |
| 按月订阅 | 自动续订，在订阅有效期内使用 Pro |
| 按年订阅 | 自动续订，在订阅有效期内使用 Pro |
| 一次买断 | 非消耗型内购，永久解锁 Pro，无需续订 |

三种方案提供相同的 Pro 权益。价格、币种和订阅条款以 App 内的 App Store 购买页面为准，购买由 Apple 的 StoreKit 处理。

## 恢复购买与管理订阅 {#restore}

在使用原购买 Apple 账号的设备上，进入 Pro 页面并点按 **恢复购买**。

需要查看或取消自动续订时，可使用 Pro 页面的 **管理订阅**，或进入系统设置中的 Apple 账号订阅管理。一次买断不自动取消已有订阅，如需停止续订，请另行管理。

恢复后仍有疑问，可通过 [帮助与反馈](/ios/#support) 联系我们。
