# 音频

Salt Player 的音频设置用于指定首选输出采样率，并查看当前播放链路的音频格式。首选值是向 iOS 提交的请求，实际输出由系统音频配置与连接设备的能力共同决定。

## 采样率设置

在**设置**中打开**音频**，点按**采样率**右侧的当前值即可选择输出偏好。

- **自动**：根据当前音源的采样率请求输出，适合日常播放。切换音源时，请求值可随音源变化，但不保证输出设备采用相同的采样率
- **固定采样率**：请求指定的输出采样率。可选范围为 44.1 kHz 至 768 kHz，列表中的值是可提交的请求，不代表当前设备支持的格式列表

如果设备或当前音频路由不支持请求值，实际输出可能采用其他采样率。切换扬声器、蓝牙耳机或 USB 音频设备后，应重新查看**音频输出信息**，以系统报告的实际输出为准。

## 采样率与音质

采样率表示数字音频每秒的采样次数，单位为赫兹（Hz）。例如，44.1 kHz 表示每秒 44,100 次采样。采样率与位深是不同的音频参数，采样率本身不能完整描述录音质量或播放音质。

提高输出采样率不会恢复音源中不存在的细节，也不保证改善音质。将 44.1 kHz 音源以更高的采样率输出，不会使其成为包含更多原始录音信息的高解析度音源。

音源与输出采样率不同时，播放链路需要进行采样率转换。实际处理还可能包括混音、音量调整及音频效果，因此采样率一致本身也不能证明音频数据未经处理。

## 不同输出设备的行为

### 内置扬声器

内置扬声器的输出采样率由设备硬件和系统音频配置决定。应用可以请求首选采样率，但无法强制系统采用硬件不支持的格式。

不同型号的设备可能具有不同的可用格式，不应将某一型号的输出采样率视为所有 iPhone 或 iPad 的固定规则。播放高采样率音源时，音频可转换为当前输出支持的采样率；选择较高的值不代表内置扬声器会以该值输出。

### 蓝牙音频

蓝牙音频的传输格式由 iOS 与连接设备协商，并受蓝牙协议、编解码器及设备能力限制。此处的采样率设置不会指定或更换蓝牙编解码器，也无法将有损的无线传输变为无损传输。

**实际输出**显示的是系统音频会话报告的采样率。它不直接表示蓝牙链路的传输格式，也不表示耳机内部数模转换器的工作采样率。较高的显示值不能作为高解析度或无损蓝牙传输的证据。

无损音源与无损传输是不同概念。播放无损文件时，后续无线链路仍可能采用有损编码；应以当前设备及连接方式的支持情况判断，不能仅凭文件格式或应用中的采样率判断。

### USB 音频

通过 USB 连接外置数模转换器（DAC）或音频接口时，可用采样率取决于外置设备的能力，以及 iOS 对当前连接与音频格式的支持。USB 是连接方式，连接 USB 设备本身并不保证支持所有采样率。

在 iPhone 或 iPad 上以高于 48 kHz 的采样率输出，需要兼容的外置数模转换器或包含数模转换功能的音频设备。设备支持的最高采样率是能力上限，不表示所有音源都应以该值播放；选择列表中的 384 kHz 或 768 kHz，也不保证系统与设备能够采用该值。

连接设备并开始播放后，可在**音频输出信息**中核对请求值与实际输出。如果外置设备提供采样率显示，也可同时核对其指示。系统报告的是当前音频会话的输出格式，外置设备内部仍可能进行额外处理。

## 阅读音频输出信息

音频页面分别显示音源、应用混音与系统输出的信息，便于区分播放链路中的不同阶段。

| 项目 | 含义 |
| --- | --- |
| 音频流 | 当前音源的采样率与声道数 |
| 请求采样率 | 当前向输出链路请求的首选采样率；自动模式下根据音源确定 |
| 音频混音器 | 应用混音阶段的采样率与声道数，不等同于最终设备输出 |
| 音频输出设备 | 当前系统音频路由中的输出设备名称 |
| 实际输出 | iOS 音频会话报告的当前采样率与输出声道数，可能与请求值不同 |

**实际输出**用于确认系统当前采用的输出格式，不能据此判断蓝牙编解码器、最终 DAC 位深或完整播放链路是否保持无损。
